# KALPAVRIKSHA
A collection of C programming assignments focused on problem-solving, input validation, file handling, and data management.

### 1. Calculator
A console-based calculator implemented in **C** that evaluates mathematical expressions using **two stacks**.

**Features:**
* Supports `+`, `-`, `*`, `/`
* Handles multi-digit numbers
* Follows **DMAS operator precedence**
* Validates expression structure and characters
* Ignores whitespace
* Handles division-by-zero errors

### 2. CRUD Operations
A console-based **CRUD (Create, Read, Update, Delete)** application implemented in C using text-file storage.

**Features:**
* Create users with unique ID, name, and age
* Read and display user records
* Update user details using ID
* Delete users using ID
* Store records in `users.txt`
* Input validation and error handling
* Temporary file handling for update and delete operations
